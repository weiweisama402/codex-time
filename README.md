# 柳比歇夫时间管理 PWA

基于柳比歇夫时间管理法的个人时间记录工具。纯静态网页应用（PWA），数据只保存在本设备，不上传任何内容；支持安装到手机主屏/电脑桌面并离线使用。

四大分类：**主要工作**（科研、论文、实验等）、**附加工作**（事务性工作、课程等）、**休闲**（休息、放松）、**娱乐**（游戏、刷剧等）。有效时间 = 主要工作 + 附加工作。

## 功能

- 手动记录：添加/编辑/删除记录，只需填写日期、时长（分钟）、分类、标题和备注，同一天按录入顺序排列；
- 统计报表：日（分类占比）、周（周一至周日 7 天堆叠柱状）、月（热力图 + 每日柱状）、年（12 个月堆叠柱状 + 明细表）；
- 数据管理：导出 JSON 备份、导出 CSV（日期/时长/分类/标题/备注）、导入恢复、清空数据；
- PWA：可安装、可离线、浅色/深色自动跟随系统。

## 本地运行

在项目根目录执行：

```powershell
python -m http.server 8080
```

然后打开 <http://localhost:8080>。service worker 与安装提示需要在 localhost 或 HTTPS 下才能启用，不能直接双击 `index.html`。

## 安装到设备

- **手机**：用浏览器打开网址，Android Chrome 选择「添加到主屏幕」，iOS Safari 选择「添加到主屏幕」；
- **电脑**：Chrome/Edge 地址栏右侧的安装图标，或菜单「安装应用」。

首次打开需联网（会缓存全部文件），之后可离线使用。

## 部署（可选）

把项目目录上传到任意静态托管即可，例如：

- **Netlify Drop**：打开 <https://app.netlify.com/drop>，登录后把整个项目文件夹拖入，即得 HTTPS 网址；
- **GitHub Pages**：推送到仓库后，在 Settings → Pages 中选择分支部署。

注意：数据存于各设备本地，多设备之间需要用「导出 JSON 备份 → 导入」迁移。

## 数据备份

在「数据」页导出 JSON 备份并妥善保存。换设备或清浏览器数据前务必先导出。

## 项目结构

```text
index.html            页面结构
css/style.css         样式（浅色/深色）
js/util.js            日期/时间/分类工具
js/db.js              IndexedDB 数据层
js/charts.js          手写 SVG 图表
js/app.js             应用逻辑
sw.js                 离线缓存
manifest.json         PWA 清单
icons/                图标（可运行 generate_icons.py 重新生成）
```

## 开发提示

- 更新静态资源后，把 `sw.js` 里的 `CACHE_NAME` 版本号 +1，浏览器才会重新缓存；
- 浏览器无痕/清除站点数据会清掉本地数据，务必定期备份。
