# Android Chrome 最终验收清单

自动化移动视口测试通过后，使用真实 Android Chrome 完成以下检查：

- 通过 HTTPS 地址打开应用，浏览器可显示“安装应用”，安装后以 standalone 模式启动；
- 首次登录可收到并输入 6 位邮箱验证码，键盘不会遮挡主要操作；
- 启动计时后切到其他应用再返回，计时没有丢失或冻结；
- 暂停、刷新、继续和停止均产生正确时长；
- 断开网络后可新增、编辑和删除记录，刷新后数据仍存在；
- 恢复网络后同步状态从“离线/待同步”变成“已同步”，电脑端可看到更新；
- 手机底部导航不与系统手势区重叠，横竖屏和深色模式显示正常；
- 有新版本时出现更新条，点击后页面刷新且本地记录不丢失；
- 导出 JSON 能调起系统下载/分享，导入前有明确替换确认；
- 使用 Android 返回键关闭弹窗或返回上一页时行为符合预期。

若某项失败，请记录：手机型号、Android/Chrome 版本、网络状态、复现步骤和截图。
