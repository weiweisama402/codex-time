# 时衡 v2 Android 最终验收清单

请分别在真实 Android Chrome 与 Edge 上完成，并记录手机型号、Android/浏览器版本。

- 在 360–480px 竖屏下打开正式 HTTPS 地址；电脑访问只显示手机二维码页；
- 从浏览器菜单安装，standalone 启动方向为竖屏，状态栏与底部手势安全区不遮挡操作；
- 软键盘弹出时仍能看到输入字段与保存按钮，系统返回键先关闭键盘/弹层；
- 启动计时，切到其他应用 5 分钟再返回，时长按真实时间增长；刷新后可暂停、继续、停止；
- 在 23:59 前开始并跨过本地午夜停止，两个日期的秒数之和等于总计时；
- 补录、编辑、复制、再次计时、删除与 10 秒撤销均可用；
- 断网后新增记录并刷新，数据仍存在；联网后备份状态最终变为“云备份已同步”；
- 用邮箱密码登录，新手机本地为空时出现恢复提示；制造双端修订分叉时不静默覆盖；
- JSON/CSV 可下载，导入前出现替换确认，错误文件不会改变现有账本；
- 浅色、深色、超长计时提醒、时区、PWA 更新提示正常；更新后本地记录不丢失。

任何失败请附：设备信息、网络状态、复现步骤和截图。
